# 🛠️ What I've Been Working On

**Payments Reconciliation Platform @ PayU**
Led the end-to-end modernization from Java 17 on Graviton ARM to **Java 21 + Spring Boot**, using virtual threads for high concurrency with zero production regressions. Integrated reconciliation and settlement into a unified post-reconciliation flow and scaled it to **2x TPS**. Built a 3-way card reconciliation engine with multi-source matching and SFTP ingestion, offloaded heavy aggregations from MySQL to **Amazon Redshift**, and hardened Kafka pipelines with graceful consumer shutdowns and fallbacks for P0 crons.

**Preference Management @ Optum**
Accessible, pixel-perfect **React** micro-frontends plus Spring Boot REST APIs distributing customer preferences across enterprise services, backed by Kafka, Redis, and MySQL for low-latency sync.

**Last Mile @ Delhivery**
React dashboards for warehouse and on-ground logistics, and **Flask** microservices processing **50,000+ daily transactions at 99.7% uptime**, deployed via AWS Lambda and Jenkins CI/CD.

# 🚀 Projects

**🔍 MCP Recon Investigator** — `Java` `MCP` `OpenSearch` `MySQL`
An AI-powered Model Context Protocol tool in Cursor that automates root cause analysis for reconciliation failures. Orchestrates OpenSearch, Redash (MySQL), GitLab, and SonarQube for contextual retrieval across logs, databases, and source code, then answers natural language queries with full RCAs and actionable production data fixes — cutting resolution time on critical P0 issues.

**✈️ AI Travel Agent (MCP)** — `Java 21` `Spring Boot` `Spring AI` `OpenAI` `PostgreSQL` `Redis` `Docker`
Full-stack AI travel planner using Spring AI + OpenAI for agent orchestration and personalized itineraries, with Redis caching, Spring Security, and a Docker Compose'd frontend/backend.

**📄 Benchmarking Java Virtual Threads in High-Throughput Workloads** — *Research Paper*
A benchmarking framework evaluating virtual threads against traditional platform threads on latency, throughput, and thread lifecycle.
